# cse-210-warm-up-graphing

Graph Tool (CSE 210 Warm Up)

## Run locally

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. From this project folder, run `npm start`.
3. Open [http://localhost:3000](http://localhost:3000) in a browser.

## Using the linter and code formatter

You can run ESLint with the following line:

`npx eslint .`

You can check your code with the code formatter using:

`npx prettier . -c`

You can automatically update your code format using:

`npx prettier . -w`
